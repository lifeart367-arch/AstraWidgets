# AstraWidgets

iOS-inspired dynamic weather widgets for Android.

## V0.1
- Native Android home-screen widget
- Horizontal and vertical resizing
- Celsius temperature
- Location, time and date
- Sunny/night presentation
- Rounded card UI
- Demo weather data, structured for a future real weather API

## Build
Open this project in Android Studio or GitHub Codespaces with an Android/Gradle environment and run:

`gradle assembleDebug`

The APK will be generated under `app/build/outputs/apk/debug/`.
